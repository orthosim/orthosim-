# ORTHO-SIM Website — Version 1

A responsive static website for ORTHO-SIM.

## Files
- `index.html` — website structure and content
- `style.css` — responsive visual design

## Free publishing
This site is designed for GitHub Pages. GitHub Pages can publish HTML/CSS/JavaScript directly from a GitHub repository.

Suggested repository name:
`orthosim`

After uploading the files:
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Select the branch containing the files and the root folder.
4. Save.
5. GitHub will provide the live `github.io` address.

A custom domain can be connected later.

## Important before launch
Replace the placeholder contact email `hello@orthosim.co.za` with the real ORTHO-SIM email address when available.
